QC Tool API

The machine-readable OpenAPI document is available as openapi.json.

Authentication

Private API endpoints require a one-time-issued credential in the HTTP Authorization header: 

Authorization: Bearer <QC Tool API credential>

Sign in to QC Tool to create or rotate your credential. Credentials in URLs and query strings are rejected because URLs are commonly retained in logs and browser history.

Example

curl --header 'Authorization: Bearer <credential>' \
  '{{ api_url }}/delivery-list'
