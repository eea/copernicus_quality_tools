A backup ZIP and a database are different things. A ZIP is a saved file you can download or restore. Restoring a full database backup creates a separate database on this server. It becomes active only after you review and confirm a switch.

{% if backup_files_url %}

Open Back up & restore to download or delete saved ZIPs. Removing a ZIP frees backup storage; it does not remove any database.

{% endif %}

After switching, keep maintenance on while checking the restored installation. Turn maintenance off when you are ready to let users make changes again.
