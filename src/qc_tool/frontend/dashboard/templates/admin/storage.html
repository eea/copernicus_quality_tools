About folder and selected-item downloads

ZIP files are streamed directly to your browser without creating another copy on the server. Keep the download connection open. The ZIP includes a report of protected, hidden or unsupported items that were excluded. Folder ZIPs include the whole folder, regardless of the search filter.

For large or resumable folder transfers, connect with SFTP. To back up database records together with files, use Database backups.
