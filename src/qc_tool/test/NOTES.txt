How to run tests for check functions
------------------------------------

Start the local stack from the repository root. The worker includes the native
geospatial dependencies and embedded PostGIS required by the check tests:

docker compose -f docker/compose.local.yaml up -d --build --wait

Run all tests without calling the external INSPIRE service:

docker compose -f docker/compose.local.yaml exec \
  -e SKIP_INSPIRE_CHECK=yes \
  worker \
  python3 -m unittest discover \
  -s /usr/local/src/copernicus_quality_tools/src/qc_tool/test \
  -t /usr/local/src/copernicus_quality_tools/src

Run a specific test module:

docker compose -f docker/compose.local.yaml exec \
  -e SKIP_INSPIRE_CHECK=yes \
  worker \
  python3 -m unittest qc_tool.test.test_vector_check

Set SKIP_INSPIRE_CHECK=no when the INSPIRE behavior itself is under test. The
local stack uses the lightweight validator by default; see README.md for the
full-validator startup command.
